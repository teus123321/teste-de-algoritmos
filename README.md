# Teste de Algoritmos

Bem-vindo ao Teste de Algoritmos. Criei este projeto com um objetivo simples: ajudar estudantes da matéria de Estrutura de Dados a testarem o tempo real de execução de seus códigos de forma prática.

Nas aulas teóricas, ouvimos muito sobre a complexidade de tempo — como uma busca linear sendo O(n) e uma busca binária O(log n). A ideia desse site é tirar isso da lousa e dar um espaço simples para você colocar dois algoritmos lado a lado e ver qual deles realmente termina primeiro no cronômetro.

## O que o projeto oferece

* Comparação lado a lado: Duas áreas independentes para você colar seus códigos e comparar a performance deles na mesma hora.
* Experiência focada: A interface é minimalista e usa fontes monoespaçadas (a mesma que você usa no seu editor de código) para tornar a leitura mais confortável.
* Leveza: O projeto não tem dependências pesadas. É carregar a página e começar a testar.

## Como foi construído

O foco aqui é a simplicidade e a performance, então mantive o desenvolvimento nas tecnologias essenciais da web:
* HTML5 para a estrutura.
* CSS3 para um visual limpo e responsivo.
* JavaScript para fazer a lógica de captura de texto e o cálculo dos milissegundos.
